СТРУКТУРА НА САЙТА (не променяй имената/нивата на папките):

  /index.html        → English версия (root, https://hackera.online/)
  /bg/index.html      → Bulgarian версия (https://hackera.online/bg/)

  /llms.txt

КАК ДА КАЧИШ В NAMECHEAP (cPanel):

1. Влез в Namecheap акаунта → Hosting List → до hackera.online натисни
   "Manage" → отвори cPanel.
2. В cPanel отвори "File Manager".
3. Влез в папката "public_html" (това е root на сайта).
4. Ако вътре вече има стари файлове на hackera.online (index.html,
   css/, js/, robots.txt и т.н.) — направи си резервно копие
   (маркирай всичко → "Compress" → изтегли zip-а локално, преди
   да презаписваш).
5. Качи (Upload) съдържанието на този zip директно в public_html,
   така че:
     public_html/index.html
     public_html/bg/index.html
     public_html/css/style.css
     public_html/js/...
   да седят точно на тези нива — НЕ вътре в допълнителна подпапка
   "hakera-static".
6. Ако File Manager разархивира в подпапка "hakera-static/",
   премести цялото съдържание едно ниво нагоре в public_html и
   изтрий празната папка.
7. Провери:
   https://hackera.online/       → трябва да зареди English версията
   https://hackera.online/bg/    → трябва да зареди Bulgarian версията

НЕ Е НУЖНО НИЩО ДРУГО В NAMECHEAP:
- Не се налага промяна на DNS записи.
- Не се налага нов domain/subdomain.
- Не се налага нов hosting план.
- Това е чисто файлова промяна на съществуващия сайт.

Ако предпочиташ FTP вместо File Manager: използвай FTP данните от
cPanel → "FTP Accounts", свържи се (напр. с FileZilla) и качи
съдържанието в /public_html/ по същия начин.

SITE STRUCTURE (keep folder names/levels exactly as-is):

  /index.html         → English version (root, https://hackera.online/)
  /bg/index.html       → Bulgarian version (https://hackera.online/bg/)
  /css/style.css

  /llms.txt

HOW TO UPLOAD ON NAMECHEAP (cPanel):

1. Log into your Namecheap account → Hosting List → next to
   hackera.online click "Manage" → open cPanel.
2. In cPanel, open "File Manager".
3. Go into the "public_html" folder (this is your site's root).
4. If there are already old hackera.online files there (index.html,
   css/, js/, robots.txt, etc.) — back them up first (select all →
   "Compress" → download the zip locally before overwriting).
5. Upload the contents of this zip directly into public_html, so
   that:
     public_html/index.html
     public_html/bg/index.html
     public_html/css/style.css
     public_html/js/...
   sit at exactly these levels — NOT inside an extra "hakera-static"
   subfolder.
6. If File Manager extracts everything into a "hakera-static/"
   subfolder, move all its contents up one level into public_html
   and delete the now-empty folder.
7. Verify:
   https://hackera.online/       → should load the English version
   https://hackera.online/bg/    → should load the Bulgarian version

NOTHING ELSE IS NEEDED IN NAMECHEAP:
- No DNS changes required.
- No new domain/subdomain required.
- No new hosting plan required.
- This is a purely file-level update to the existing site.

If you prefer FTP over File Manager: get your FTP credentials from
cPanel → "FTP Accounts", connect (e.g. with FileZilla), and upload
the contents into /public_html/ the same way.
